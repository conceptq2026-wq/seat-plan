প্রথমবার সেটআপ: রিপোর মালিক একবার GitHub টোকেন দিয়ে প্রথম এডমিন তৈরি করবেন। এরপর থেকে শুধু নাম ও পাসওয়ার্ড দিয়ে লগইন।
টোকেন কীভাবে বানাবেন?
  1. রিপোর মালিকের অ্যাকাউন্টে লগইন করে এই লিংকে যান
  2. Token name: seat-plan-admin, Expiration: পছন্দমতো (যেমন ১ বছর)
  3. Repository access: Only select repositories → এই রিপো
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token চেপে টোকেনটি কপি করে এখানে বসান

রিপোর মালিক সরাসরি GitHub টোকেন দিয়ে ঢুকতে পারেন। ঢুকে "স্কুলের তথ্য, রং ও ব্যাকআপ" অংশ থেকে এডমিন তৈরি করা যায়।

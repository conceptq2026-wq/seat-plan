# পরীক্ষার আসনবিন্যাস (Seat Plan)

স্কুলের পরীক্ষার আসনবিন্যাস তৈরি ও প্রকাশের ওয়েবসাইট। পুরোপুরি GitHub Pages-এ চলে, কোনো সার্ভার বা খরচ লাগে না।

- **শিক্ষার্থীদের পাতা** (`index.html`): শ্রেণি ও রোল দিলে "আসন টিকিট" দেখায়, যাতে কক্ষ, বেঞ্চ, আসন আর কক্ষের ছোট নকশা থাকে। টিকিট ছবি হিসেবে সেভ বা শেয়ার করা যায়, আর প্রতিটি আসনের নিজস্ব লিংক কপি করা যায়। ফোনে কক্ষগুলো ছোট নকশায় দেখায়।
- **এডমিন পাতা** (`admin.html`): নতুন সিট প্ল্যান তৈরি, কক্ষ যোগ, স্বয়ংক্রিয় বণ্টন, সিটে ক্লিক করে বসানো বা ব্লক করা, টেনে সিট বদলানো, Undo, প্রিন্ট, Word ফাইল, আর এক ক্লিকে ওয়েবসাইটে প্রকাশ।

সব ডেটা থাকে [`data/plans.json`](data/plans.json) ফাইলে। এডমিন "প্রকাশ করুন" চাপলে এই ফাইলটি GitHub-এ হালনাগাদ হয়।

---

## প্রথমবার চালু করা

### ১. GitHub Pages চালু করুন
1. রিপোর **Settings → Pages** এ যান।
2. **Source:** `Deploy from a branch`, **Branch:** `main` এবং `/ (root)` বেছে নিয়ে **Save** চাপুন।
3. ১-২ মিনিট পর সাইট চালু হবে: `https://<অ্যাকাউন্ট>.github.io/<রিপো>/`
   - শিক্ষার্থীদের লিংক: `…/seat-plan/`
   - এডমিন লিংক: `…/seat-plan/admin.html`

### ২. এডমিনের টোকেন (গোপন চাবি) তৈরি করুন
1. রিপোর মালিকের অ্যাকাউন্টে লগইন করে যান: https://github.com/settings/personal-access-tokens/new
2. **Token name:** `seat-plan-admin`, **Expiration:** পছন্দমতো (যেমন ১ বছর)
3. **Repository access:** `Only select repositories` → এই রিপো
4. **Permissions → Repository permissions → Contents:** `Read and write`
5. **Generate token** চেপে টোকেনটি কপি করুন।

### ৩. প্রথম এডমিন তৈরি করুন
1. `…/seat-plan/admin.html` খুলুন। কোনো এডমিন না থাকলে **"প্রথমবার সেটআপ"** পাতা আসবে।
2. টোকেন, ব্যবহারকারীর নাম (ইংরেজিতে, যেমন `head`) আর পাসওয়ার্ড (অন্তত ১০ অক্ষর) দিন।
3. এরপর থেকে যেকোনো ডিভাইসে শুধু **নাম + পাসওয়ার্ড** দিয়ে লগইন। টোকেন আর লাগবে না।
4. আরও শিক্ষককে এডমিন করতে: **🏫 স্কুলের তথ্য, রং ও ব্যাকআপ → 👤 এডমিন ও লগইন → ➕ নতুন এডমিন**।

> ⚠ টোকেন আর পাসওয়ার্ড কাউকে দেবেন না। যার কাছে টোকেন আছে সে-ই সাইটে পরিবর্তন প্রকাশ করতে পারে। টোকেন হারালে বা ফাঁস হলে GitHub-এর একই পাতা থেকে মুছে নতুন একটা বানান।

## ব্যবহার

1. `admin.html` খুলুন → **➕ নতুন সিট প্ল্যান** চাপুন। চাইলে আগের প্ল্যান থেকে কক্ষগুলো কপি করে নিন।
2. সেশন বেছে নিন (সকাল/বিকাল, বা **➕ সেশন** দিয়ে নতুন) → **নতুন কক্ষ যোগ করুন**।
3. **স্বয়ংক্রিয় আসন বণ্টন** দিয়ে রোল রেঞ্জ বসান (যেমন `১-৪০` বা `১-১০, ১৫, ২০-২৫`)।
   - বেঞ্চ নম্বর চার্টের নম্বরই। বাম সারি ১-৮ হলে ডান সারি ৯ থেকে শুরু।
   - একই শিক্ষার্থী দুবার বসানো হয় না।
4. একজনকে বসাতে, ব্লক করতে বা সরাতে চার্টের সিটে ক্লিক করুন। মাউস দিয়ে টেনেও সিট বদলানো যায়।
   - **অনেক কক্ষ একসাথে:** "📥 শিক্ষার্থী বণ্টন শুরু করুন" দিয়ে কয়েকটি শ্রেণির রোল কয়েকটি কক্ষে একসাথে ভাগ করুন। "পাশাপাশি ভিন্ন শ্রেণি" বাছলে দাবার ঘরের মতো বসবে।
   - **Excel/CSV থেকে:** একই জানালায় "📄 Excel/CSV ফাইল থেকে নিন"। কলাম: শ্রেণি, শাখা, শিফট, বিভাগ, রোল (নমুনা ফাইল সেখানেই পাবেন)। নামের কলাম থাকলে বাদ দেওয়া হয়, নাম ওয়েবসাইটে যায় না। পুরনো `.xls` হলে `.xlsx` বা CSV হিসেবে সেভ করে দিন।
   - **সংরক্ষিত কক্ষ:** কক্ষ যোগ করলে তালিকায় জমা থাকে। পরের পরীক্ষায় "📚 সংরক্ষিত কক্ষ থেকে যোগ" দিয়ে টিক দিয়ে এক চাপে সব কক্ষ নিন।
5. **"শিক্ষার্থীদের দেখাবে"** টিক দিন → **🚀 ওয়েবসাইটে প্রকাশ করুন**।

প্রকাশ না করা পরিবর্তন ওই কম্পিউটারের ব্রাউজারে খসড়া হিসেবে থাকে, তাই পেজ বন্ধ হলেও হারায় না। প্রকাশের পর ওয়েবসাইটে দেখা যেতে সাধারণত ১-২ মিনিট লাগে, কখনো ১০ মিনিট পর্যন্ত।

আগের একক-ফাইলের `seat_plan_system.html` থাকলে **🏫 স্কুলের তথ্য, রং ও ব্যাকআপ → পুরনো HTML ফাইল ইমপোর্ট** দিয়ে যোগ করা যায়।

## এডমিন লগইন কীভাবে কাজ করে

- GitHub টোকেনটি একটি গোপন চাবি দিয়ে তালাবদ্ধ হয়ে [`data/admins.json`](data/admins.json)-এ থাকে। প্রতিটি এডমিনের পাসওয়ার্ড (PBKDF2, ৬ লাখ ধাপ → AES-GCM) সেই চাবি খোলে। পাসওয়ার্ড বা খোলা টোকেন কোথাও জমা থাকে না।
- ফাইলটি public রিপোতে থাকে, তাই **লম্বা পাসওয়ার্ড** দিন (১০+ অক্ষর, শব্দ-সংখ্যা মিশিয়ে)। ছোট বা সহজ পাসওয়ার্ড অনুমান করে খোলা সম্ভব।
- টোকেনের মেয়াদ শেষ হলে যেকোনো এডমিন **🔑 GitHub টোকেন বদলান** দিয়ে নতুন টোকেন দিলে সবাই আগের পাসওয়ার্ডেই কাজ করবেন।
- কারও পাসওয়ার্ড ভুলে গেলে অন্য এডমিন তার **পাসওয়ার্ড বদলান** দিতে পারেন। সবাই ভুলে গেলে রিপোর মালিক "টোকেন দিয়ে প্রবেশ" করে **সব এডমিন নতুন করে সেটআপ** করতে পারেন।
- `data/admins.json` হাতে বদলাবেন না।

## অন্য GitHub অ্যাকাউন্টে নেওয়া

কোডে কোনো অ্যাকাউন্ট বা রিপোর নাম লেখা নেই। ঠিকানা (`xxx.github.io/yyy`) দেখে সাইট নিজেই রিপো চিনে নেয়।

1. পুরনো এডমিন পাতায় সব পরিবর্তন **প্রকাশ** করা আছে কিনা দেখে নিন।
2. পুরনো অ্যাকাউন্টে রিপোর **Settings → General → (একদম নিচে) Danger Zone → Transfer ownership** → নতুন অ্যাকাউন্টের নাম লিখে নিশ্চিত করুন। সব ফাইল, ইতিহাস ও ডেটা সাথে যাবে।
3. নতুন অ্যাকাউন্টে **Settings → Pages** চালু করুন (উপরের ধাপ ১)। নতুন ঠিকানা: `নতুন-অ্যাকাউন্ট.github.io/seat-plan`
4. নতুন অ্যাকাউন্ট থেকে **নতুন টোকেন** বানান (উপরের ধাপ ২)। পুরনো টোকেন আর কাজ করবে না।
5. নতুন ঠিকানার `admin.html`-এ **আগের নাম-পাসওয়ার্ড দিয়েই লগইন** করুন। টোকেন কাজ না করায় "টোকেন বদলান" জানালা নিজে থেকে আসবে, সেখানে নতুন টোকেন দিন। সব এডমিন আবার কাজ করবেন।
   (আগে কোনো এডমিন বানানো না থাকলে "প্রথমবার সেটআপ" করুন।)
6. শিক্ষার্থীদের নতুন ঠিকানা জানিয়ে দিন। পুরনো ঠিকানা আর কাজ করবে না।

চাইলে Transfer-এর বদলে নতুন অ্যাকাউন্টে নতুন রিপো খুলে **Import repository** (github.com/new/import) দিয়ে পুরনো রিপোর ঠিকানা দিলেও সব কপি হয়ে যায়। এরপর ধাপ ৩ থেকে একই।

নিজস্ব ডোমেইন (custom domain) ব্যবহার করলে [`assets/config.js`](assets/config.js) ফাইলে `owner` ও `repo` লিখে দিন।

## জেনে রাখুন

- ফ্রি GitHub Pages-এর জন্য রিপো **Public** রাখতে হয়। তাই `data/plans.json` (শ্রেণি, শাখা, রোল, কক্ষ) যে কেউ দেখতে পারে। শিক্ষার্থীর নাম বা ফোন নম্বরের মতো ব্যক্তিগত তথ্য এখানে রাখবেন না।
- নিয়মিত **⬇ ব্যাকআপ ডাউনলোড** করে রাখা ভালো। তবে GitHub নিজেও প্রতিটি প্রকাশের পুরনো সংস্করণ রেখে দেয় (রিপোর `data/plans.json` → History)।
